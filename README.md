# Rock, Paper, Scissors Game 

A simple command-line game built using Python.

## About the Project

This project lets a player compete against the computer in Rock, Paper, Scissors. The computer randomly selects a choice, and the program determines the result using conditional statements.

## Features

- Player input
- Random computer choice
- Winner determination
- Draw detection

## Technologies Used

- Python 3
- `random` module

## Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Matching choices result in a draw.

## How to Run

Clone the repository:

```bash
git clone https://github.com/loomlogic01/rock-paper-scissors-python.git
```

Enter the project folder:

```bash
cd rock-paper-scissors-python
```

Run the game:

```bash
python Rock_paper_scissor_game_in_python.py
```
